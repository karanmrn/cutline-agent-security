CUTLINE reference card

Stop attack.
Keep agent useful.

CUTLINE turns one synthetic autonomous-agent incident into a narrow policy and a replay that proves the harmful action is blocked while the useful code fix survives.

The five-step mental model

01 ObserveMonitor runFresh fixture. Fake canary reaches only the in-memory collector.
02 ExplainEvidence chainUntrusted rule → secret read → external write, linked by event IDs.
03 ConstrainPolicyDeny secret external writes outside the session allowlist.
04 ApproveHuman gateApproval binds policy ID, version, hash, and provider.
05 ProveFresh replayNew fixture. Egress blocked. Code fix and tests pass.

Your 30-second answer

“An agent follows a poisoned workspace instruction and tries to upload a fake secret. CUTLINE records the causal evidence, selects the lowest-disruption rule from four curated candidates, gets human approval, and replays the task in a fresh fixture. The upload is blocked, but the code fix and tests still succeed. The result becomes a digest-bound regression manifest.”

Claim discipline

Say: “The local deterministic replay is verified.”

Do not say: “All integrations are production-ready.” Modal, Langfuse, Overmind, Supabase, and Ossprey are separate, opt-in, and unverified unless live smoke evidence exists.
