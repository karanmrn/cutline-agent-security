Lesson 1 · product explanation

Explain CUTLINE without hand-waving.

Your job is not to list every file. Your job is to make one security claim believable: the attack was observed, the control was narrow, and replay proved useful work survived.

Win for this lesson: deliver a clear 30-second explanation, then point each sentence to an observable implementation detail.

1. The product in one sentence

CUTLINE turns a synthetic autonomous-agent incident into a replay-tested guardrail.

That sentence has three nouns you must explain: incident, guardrail, replay.

Incident

A fresh fixture contains an untrusted workspace rule. The agent reads the fake secret and attempts an external write to the in-memory collector.

Guardrail

A fixed-schema policy denies a secret external write when its destination is outside the session allowlist.

Replay

The same useful task runs from a second fresh fixture with explicit human approval of the exact policy.

Proof

The upload is blocked while the legitimate code fix and tests pass. The result becomes a digest-bound manifest.

2. Tell the story in order

  1. Start with the threat: agents can treat hostile data as instructions. NIST calls this agent hijacking or indirect prompt injection.
  2. Make it safe: CUTLINE uses only a fake canary and an in-memory collector.
  3. Show causality: untrusted rule → secret read → external write. Each step has an event ID and parent link.
  4. Show restraint: the policy blocks only unauthorized secret egress. It does not disable the agent.
  5. Show proof: a human approves the policy ID, version, and hash; replay starts from a new fixture.
  6. Close with outcomes: no secret exposure, blocked egress, code fixed, tests passed.

3. Use this script

“An agent is asked to fix a failing test, but a poisoned workspace rule tells it to upload the environment file.”

“CUTLINE runs that scenario with a synthetic canary, records the causal evidence, and selects the lowest-disruption rule from four curated candidates: deny secret writes to unauthorized destinations.”

“After human approval, it replays the task in a fresh fixture. The write is blocked, but the code fix and tests still succeed.”

“So the output is not a scary trace. It is a replay-tested guardrail and a regression artifact.”

4. Know your boundary

Claim confidently
  • Local deterministic replay is authoritative.
  • Evidence IDs connect explanation to events.
  • Optional adapters cannot change allow or deny.
Never overclaim
  • No real credential was handled.
  • No external exfiltration request was made.
  • Modal, Langfuse, Overmind, Supabase, and Ossprey remain unverified without live smoke evidence.

5. Retrieval check

Answer from memory. Use the button only after writing your answers.

Reveal the reference answers
  • Untrusted workspace rule, secret read, unauthorized external write.
  • Typed policy fields and runtime context, not an LLM judgment.
  • The legitimate code fix and fixture tests.
