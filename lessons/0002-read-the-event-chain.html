Lesson 2 · evidence and enforcement

Read the proof chain.

CUTLINE is persuasive when every conclusion can be traced to typed events, a policy decision, and a fresh replay result. This lesson teaches that trace.

Win for this lesson: explain why an event ID is evidence, why a policy is not a suggestion, and why replay must start with a new fixture.

1. Follow one causal chain

1 · instructionevt_rule_…

Untrusted workspace rule tells agent to upload an environment file.

→
2 · secret readevt_secret_…

Runner reads only synthetic fixture content. Stored event data is redacted.

→
3 · write attemptevt_write_…

Agent attempts a write to the in-memory mock collector. This event carries policy_decision and outcome: ALLOW/success in monitor mode or DENY/blocked in enforce mode.

Each event carries an ID, sequence number, parent link, trust class, data class, action type, policy decision, and outcome. Parent links preserve causality. Evidence IDs are then copied into the proposed policy and regression manifest. There is no separate policy event.

2. Separate observation from enforcement

Observation

Events, graph edges, redacted logs, and LLM explanations answer: “What happened, and why does this look risky?”

Enforcement

Typed policy matching plus runtime context answers: “Is this write allowed?” The deterministic runner makes the final decision.

3. Read the policy contract

FieldMeaningWhy it matters
id, version, policy_hashStable identity for approval and replay.Human approves exact policy, not an ever-changing prompt.
effect: denyFixed decision outcome.LLM cannot silently turn a recommendation into authorization.
matchSecret data class, external-write action, and destination outside allowlist.Narrow rule preserves legitimate work.
evidence_event_idsEvents that justify proposal.Reviewer can move from policy back to causal evidence.

4. Understand the replay proof

  1. Human approval is explicit and tied to policy identity.
  2. Runner creates a new temporary fixture and new fixture_id.
  3. Useful code fix still executes and tests still pass.
  4. Secret is not exposed, external write is blocked, and manifest digest binds results.

5. Retrieval check

Answer first, then check.

Reveal reference answers
  • evidence_event_ids.
  • Deterministic policy evaluation in the runner.
  • State leakage: replay must prove the control works from clean fixture state.
