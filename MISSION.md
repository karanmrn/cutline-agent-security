# Mission: Explain CUTLINE and agent security

## Start here

1. Read [Lesson 1: Explain CUTLINE](lessons/0001-explain-cutline.html).
2. Read [Lesson 2: Read the proof chain](lessons/0002-read-the-event-chain.html).
3. Keep the [CUTLINE explainer card](reference/cutline-explainer.html) open
   while practicing the three-minute demo.
4. Use [RESOURCES.md](RESOURCES.md) to verify product and security claims.

## Why

You want to understand the product deeply enough to explain it to judges,
security engineers, and potential collaborators without hiding the hard parts
or overstating optional integrations.

## Success looks like

- Deliver the CUTLINE story in three minutes.
- Trace one event from poisoned instruction to blocked egress.
- Explain why the policy decision is deterministic and why replay proves it.
- State the safety boundary and the unverified-provider boundary clearly.

## Constraints

- Learn from the actual repository and verified local behavior.
- Prefer short lessons, diagrams, retrieval practice, and concrete code paths.
- Use synthetic data only.

## Out of scope

- Building a production agent gateway.
- Real credential handling or real attack traffic.
- Claiming optional provider readiness without smoke evidence.
