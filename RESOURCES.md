# CUTLINE Resources

## Knowledge

- [NIST: Strengthening AI Agent Hijacking Evaluations](https://www.nist.gov/news-events/news/2025/01/technical-blog-strengthening-ai-agent-hijacking-evaluations)
  Use for the security context: indirect prompt injection can cause an agent to
  take harmful actions such as exfiltration.
- [CUTLINE Product Requirements](docs/PRD.md)
  Use for the exact product story, scope, and acceptance criteria.
- [CUTLINE Threat Model](docs/THREAT_MODEL.md)
  Use for the synthetic attack path and safety constraints.
- [CUTLINE Context and Glossary](CONTEXT.md)
  Use for project-specific terms such as evidence chain, session allowlist,
  deterministic enforcement, and regression manifest.
- [FastAPI response models](https://fastapi.tiangolo.com/tutorial/response-model/)
  Use for understanding how typed API responses validate and filter data.
- [React: Thinking in React](https://react.dev/learn/thinking-in-react)
  Use for understanding component boundaries, state, and one-way data flow.
- [pytest invocation](https://docs.pytest.org/en/stable/how-to/usage.html)
  Use for understanding the backend test command and targeted test selection.

## Wisdom

- [NIST Center for AI Standards and Innovation](https://www.nist.gov/artificial-intelligence)
